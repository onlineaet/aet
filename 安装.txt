# AET 编译器安装向导

AET 是基于 GCC 15.2.0 修改扩展的编译器。

当前安装环境：
  Ubuntu 24.04
  GCC 15.2.0

整个编译过程通常需要 25～60 分钟，具体取决于网络速度与CPU性能。

推荐配置：
  4GB 以上内存
  20GB 以上磁盘空间
  4 核 CPU

第一步：下载 GCC 15.2.0 源码

官方下载地址：
https://gcc.gnu.org/mirrors.html
如果下载速度慢，可使用国内镜像：
阿里云镜像：
https://mirrors.aliyun.com/gnu/gcc/gcc-15.2.0/
清华镜像：
https://mirrors.tuna.tsinghua.edu.cn/gnu/gcc/gcc-15.2.0/

下载完成后得到：
gcc-15.2.0.tar.xz

第二步：下载 AET 源码

执行：
mkdir -p /home/my/aetgit
cd /home/my/aetgit
git clone https://github.com/onlineaet/aet.git

第三步：建立工作目录并解压 GCC

创建工作目录，之后安装过程都与 /home/my/aet2.0相关。
mkdir -p /home/my/aet2.0
cd /home/my/aet2.0

解压 GCC：
复制第一步下载的gcc-15.2.0.tar.xz到/home/my/aet2.0，并执行
tar -xf gcc-15.2.0.tar.xz

GCC解压后目录结构如下：
/home/my/aet2.0
    ├── gcc-15.2.0
        ├── config
        ├── gcc
        ├── libcpp
        └── ...

第四步：复制 AET 源码到 GCC

将 AET 中的 gcc 和 libcpp 覆盖 GCC 原始源码。
cd cd /home/my/aet2.0
cp -R /home/my/aetgit/aet/src/gcc/*    /home/my/aet2.0/gcc-15.2.0/gcc/
cp -R /home/my/aetgit/aet/src/libcpp/* /home/my/aet2.0/gcc-15.2.0/libcpp/

如果提示：
overwrite?
请选择：
yes

第五步：安装依赖库

执行：
sudo apt update
sudo apt install -y \
    build-essential \
    flex \
    bison \
    gawk \
    texinfo \
    libgmp-dev \
    libmpfr-dev \
    libmpc-dev \
    libisl-dev \
    zstd \
    libzstd-dev \
    libz-dev

第六步：编译 AET

⚠ 注意：
GCC 不允许在源码目录内直接编译。
必须使用独立 build 目录（out-of-tree build）。

1. 创建独立 build 目录
执行：
cd /home/my/aet2.0
mkdir build
cd build

2. 配置 GCC/AET

下面配置"--prefix=/home/my/aet2.0/install"会将 AET 安装到：
/home/my/aet2.0/install

../gcc-15.2.0/configure \
    --enable-languages=c,c++ \
    --disable-multilib \
    --disable-bootstrap \
    --disable-symvers \
    --prefix=/home/my/aet2.0/install
    
3. 开始编译
启用全部 CPU 核心并行编译：
make -j$(nproc)

4. 安装
make install

安装完成后：
/home/my/aet2.0/install/bin/gcc
即为 AET 编译器。

第七步：配置 PATH

临时生效（当前终端）

执行：
export PATH=/home/my/aet2.0/install/bin:$PATH

永久生效
执行：

echo 'export PATH=/home/my/aet2.0/install/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

第八步：验证安装

执行：
which gcc

输出应类似：
/home/my/aet2.0/install/bin/gcc

然后执行：
gcc --version


如果输出类似：
gcc (AET 2.0.0) 15.2.0
即表示安装成功。


第九步：测试 AET

创建测试文件：

vim test.c

内容如下：

#include <stdio.h>

class$ Test{
    void hello();
};

impl$ Test{
    void hello(){
        printf("hello world\n");
    }
};

int main()
{
    Test *t = new$ Test();
    t->hello();
    return 0;
}


编译：
gcc test.c -o test
./test

输出：
hello world

表示 AET 工作正常。


# 常见问题

1. configure: error: GMP/MPFR/MPC not found

说明缺少依赖库。

重新执行：
sudo apt install -y \
    libgmp-dev \
    libmpfr-dev \
    libmpc-dev

2. 不要在 GCC 源码目录直接 make
例如:
cd gcc-15.2.0
make
禁止这样编译：

正确方式：

mkdir build
cd build
../gcc-15.2.0/configure ...
make

3. 修改源码后建议重新 build

如果修改过 GCC/AET 源码，建议删除旧 build：

rm -rf build
mkdir build
cd build


然后重新 configure 与 make。

# 安装完成

至此，AET 编译器已经安装成功。
